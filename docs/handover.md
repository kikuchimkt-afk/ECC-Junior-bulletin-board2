# ECC Junior 掲示板アプリ 引き継ぎ資料

## 1. アプリ概要とコンセプト
このアプリは、徳島地域の ECC Junior（ジュニア・ベストワン）の運営を円滑にし、保護者や講師への情報伝達をデジタル化・効率化するために開発されました。

### コンセプト
- **「親しみやすさと信頼感」**: 柔らかい色使いと直感的な操作性。
- **「確実な情報伝達」**: 教室ごとの出し分け、メール通知による周知。
- **「運用の省力化」**: CSVによる一括登録や、PDFの直接閲覧機能。

## 2. 主要機能一覧
- **掲示板機能**: 
    - 配信日・教室・対象者（生徒/講師）に応じたお知らせ表示。
    - PDF資料の直接閲覧。
    - メッセージ内URLの自動リンク化。
- **ユーザー管理**: 
    - 3つの権限（管理者、講師、生徒）によるアクセス制御。
    - 教室ごとのフィルタリング。
- **通知システム**: 
    - 新規投稿時のメール自動送信（Brevo API利用）。
    - プライバシーに配慮したBCC送信。
- **管理ツール**: 
    - ユーザーのCSV一括登録・エクスポート（テンプレート対応）。
    - 詳細なアクセスログの監視。

## 3. 技術スタック
- **Frontend/Backend**: Next.js (App Router)
- **Database**: Vercel KV (Redis)
- **Email API**: Brevo
- **Storage**: Vercel Blob (PDF/Asset用)
- **Styling**: Vanilla CSS (Custom propertiesによるテーマ管理)

## 4. 特徴的な設計
### 柔軟な教室管理
`src/app/lib/schools.js` にて各教室の色や名称を一元管理しています。教室の追加や変更は、このファイルを修正するだけでアプリ全体に反映されます。

### 講師限定フラグ
管理者や講師にしか見えない「トップシークレット」的な業務連絡も、掲示板上で安全に行うことが可能です。

### 堅牢なCSV処理
引用符を考慮したステートベースのCSVパーサーを独自実装しており、Excelなどで作成したCSVを高い互換性で取り込めます。
